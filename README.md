# EDA NYC Taxi Analysis

An exploratory data analysis project investigating patterns, trends, and insights from NYC taxi trip data.

## 📋 Project Overview

This repository contains a comprehensive exploratory data analysis (EDA) of NYC taxi data, examining trip characteristics, fare patterns, temporal trends, and spatial distribution of taxi services across New York City.

## 📁 Repository Contents

- **EDA_NYC_Taxi_Analysis_Akul_Bharadwaj_B_H.ipynb** - Main Jupyter Notebook containing the complete EDA with data exploration, visualizations, and insights
- **EDA_NYC_Taxi_Analysis_Akul_Bharadwaj_B_H.pdf** - PDF report of the analysis findings

## 🔍 Analysis Highlights

This analysis explores:
- **Trip Patterns** - Distance, duration, and frequency distributions
- **Fare Analysis** - Pricing patterns and relationships with trip characteristics
- **Temporal Trends** - Variations by time of day, day of week, and seasonality
- **Spatial Distribution** - Geographic patterns and hotspots in NYC
- **Statistical Insights** - Correlations, outliers, and key metrics

## 🛠️ Technologies & Tools

- **Python** - Data analysis and visualization
- **Jupyter Notebook** - Interactive analysis environment
- **Libraries**: pandas, numpy, matplotlib, seaborn, geopandas
